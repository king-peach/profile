首先先说一下他们的定义：

**位运算符：位运算符处理32位数，使用该运算符的运算中的任何数值运算数都会被转成32位整数，结果会被转换成javaScript数**

**逻辑运算符：逻辑运算符用来进行逻辑运算，判断变量或者之间的逻辑关系**

下面我们来看下他们的具体操作符的含义

## 逻辑运算符

逻辑运算符通常用于布尔型(逻辑)值。这种情况下，他们返回一个布尔值，然后&&和 || 运算符会返回一个指定操作数的值，因此，这些运算符也用于非布尔值。这时，他们也会返回一个非布尔值。

逻辑运算符如下图所示(其中expr可能是任何一种数据类型，不一定是布尔值): 

  

![image.png](语雀备份/javaScript疑难梳理/assets/位运算符和逻辑运算符-2.png)

  

其中的expr可以是任意类型值，如果要将其转换成布尔类型值，有两种方法： ①使用非运算符（！！）来处理非布尔型值 ②使用Boolean构造函数来显示转换，还有一些常见的被转换称false的表达式有：

-   null
-   NaN
-   0
-   空字符串("" or '' or \`\`)
-   undefined

### 短路运算

由于逻辑表达式在相同优先级下是从左至右的，所以可以用以下规则进行"短路"计算：

-   （some false expression） && (expr) 短路计算结果为假
-   （some true expression） || (expr) 短路计算结果为真

短路意味着上诉表达式不需要全部被执行，当左边操作数被确定以后，表达式的值也就确定了，我们来看一个简单的示例： 

  

```javascript
/* 短路计算情况一 */
false && 1 
// false

/* 短路计算情况二 */
true || 100 
// true
```

  

请注意，当存在运算符优先级时，表达式的结果可能就不同了，比如小括号包裹起来的操作将变成独立的表达式

  

```javascript
false && true || true // 结果为true
false && (true || true) // 结果为false
```

  

### 逻辑与（&&）

列举一些逻辑与（&&） 的示例

  

```javascript
test1 = true && true // 返回true
test2 = true && false // 返回false
test3 = false && true // 返回false
test4 = false && (3 || 4)  // 返回false
test5 = 'car' && 'dog' // 返回'car'
test6 = false && 'dog' // 返回false
test7 = '' && 'cat' // 返回''
test8 = 'cat' && false // 返回false
test9 = false && '' // 返回false
test10 = '' && false // 返回''
```

  

### 逻辑或（||）

列举一些逻辑或（||）的示例

  

```javascript
test1 = true || true // 返回true
test2 = false || true // 返回false
test3 = true || false // 返回true
test4 = 'cat' || 'dog' // 返回'cat'
test5 = false || (3 == 4) // 返回false
test6 = 'cat' | false // 返回'cat'
test7 = '' || 'cat' // 返回'cat'
test8 = false || '' // 返回''
test9 = false || 'cat' //返回'cat'
```

在或与逻辑表达式中我总结了一下，除了短路计算以外可以更加具体的表现为：

逻辑或（||） ： 左值为true时，取左值，左值为false时，取右值

逻辑与（&&）： 左值为true时，取右值，左值为false时，取左值

  

### 逻辑非（!）

列举一些逻辑非(!)运算符的示例

  

```javascript
test1 = !true // 返回false
test2 = !false // 返回true
test3 = !'' // 返回true
test4 = !'Cat' // 返回false
```

  

双重非(!!) 运算符主要是显式地将任意值强制转换成其对应地布尔值。同样得Boolean构造函数也可以达到相同的效果,示例：

  

```javascript
test1 = !!true // 返回true
test2 = !!false // 返回false
test3 = !!{} // 返回true
test4 = !!(new Boolean(false)) // 返回false
test5 = !!"" // 返回false
test6 = Boolean(1) // 返回1
test7 = !!Boolean(1) // 返回true
```
