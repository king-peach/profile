安装后没注意初始密码，然后搜索解决方案，重置密码，开始进行的步骤是

- 开启免密登录模式，查找到`my.cnf`文件，设置`skip-grant-tables`
- 直接登录，进入`mysql`数据库（`use mysql`）
- 使用重置密码的语句 `UPDATE user SET authentication_string=PASSWORD(’123456’) WHERE user=’root’;`
- 执行以后报错，当前版本不支持`PASSWORD`函数，因为`MySQL8` 直接删除了该函数，所以继续找解决方案
- 通过搜索引擎找到了`MySQL8`的重置密码语句 `ALTER USER 'root'@'localhost' IDENTIFIED BY '123456';`
- 执行以后仍然报错，提示免密登录模式下不允许使用以上语法，所以接着找解决方案
- 后面发现可以把密码设置成null以后再重新登入后，将免密模式关掉，然后再重启MySQL后，使用无密码登录模式进入后，再用以上语法修改密码即可，具体操作如下：

```sql
// 将密码设置成null
UPDATE user SET authentication_string=null WHERE user=’root’;
// 刷新权限并推出
FLUSH PRIVILEGES;
exit;

// 将my.cnf文件中的免密登录配置注释
# skip-grant-tables

// 重启mysql
systemctl restart mysqld
// 登录并重置密码，需要注意的是mysql默认开启了密码格式校验，需要设置强类型密码，否则不成功！
mysql -u root
use mysql;
ALTER USER 'root'@'localhost' IDENTIFIED BY 'Qwer1234!';
FLUSH PRIVILEGES;
exit;
```


如何以上操作都不能重置密码，那可以重装mysql，重装成功后，注意看安装成功日志，里面会附带登录初始密码！
